# Swiggy Landing Page Clone

Responsive Swiggy-inspired homepage built with HTML5 and CSS3.

- `index.html` — page structure and content
- `style.css` — layout, colors, typography and responsive breakpoints
- `assets/` — local SVG illustration assets
- `screenshots/` — desktop and mobile preview captures

Open `index.html` in a browser or use VS Code Live Server. Search, location and app actions are visual placeholders; no JavaScript or backend is included.
